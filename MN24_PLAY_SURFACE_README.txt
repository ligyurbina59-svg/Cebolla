MN24 PLAY SURFACE v1.0
======================
Archivos:
- MN24_PLAY_SURFACE_v1.0.apk   → instalar en Android / Android TV (sideload)
- MN24_PLAY_SURFACE_v1.0.html  → abrir en navegador (PC, TV browser, pruebas)
- NORDIC_THRONE_REDEMPTION_v1.0.apk / .html (juego hermano, si está en la misma carpeta)

INSTALAR APK (teléfono)
1. Copia el .apk al teléfono (USB, Drive, Telegram…).
2. Ajustes → Seguridad → permitir instalar apps desconocidas (para el explorador de archivos).
3. Abre el APK e instala.

SMART TV
- Android TV: sideload del mismo APK (USB o ADB). Activa modo TV dentro de la app.
- Otros TV: abre el .html en el navegador del televisor si lo permite.

SMARTWATCH
- Modo Watch en la app (companion de 4 botones).
- Cámara Fotos/Demora/1p = app del fabricante del reloj + teléfono, no este APK.

CD / DVD / USB
- Un CD no instala software en Android como en un PC antiguo.
- Usa el CD/USB solo como ARCHIVO: copia APK + HTML + este README.
- Distribución real a usuarios: enlace de descarga, Drive, GitHub Releases, o Play Store.

PUBLICAR EN PLAY STORE (resumen)
1. Cuenta Google Play Console (pago único de registro).
2. Generar keystore de subida (no uses solo el debug de este build para producción).
3. Preferible AAB; cumplir políticas de contenido, privacidad y permisos.
4. No declarar el juego como competidor AAA ni “5D igual al mercado mundial”.
